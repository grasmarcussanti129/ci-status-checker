# Contributing to CI Status Checker

We welcome contributions to improve the CI Status Checker project! Follow these guidelines to help us maintain a clean and cohesive codebase.

## Issues
- Before creating a new issue, please search existing issues to avoid duplicates.
- Be clear and concise when describing a bug or feature request.

## Pull Requests
- Fork the repository and create a new branch for your feature or bug fix.
- Ensure your code meets the existing style guidelines.
- Write clear commit messages.
- Submit a pull request and describe what your changes accomplish.

Thank you for your contributions!
